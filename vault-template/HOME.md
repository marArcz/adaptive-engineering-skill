# Engineering Vault

A local **Obsidian vault backed by your own Git repository**, read by Codex and Antigravity only on a justified research fallback.

- [[INDEX]] — navigation and retrieval rules
- [[knowledge/principles/engineering-decisions]] — universal principles

**Precedence:** Project-local conventions > reviewed vault guidance > researched external evidence, except unsafe/incompatible local patterns or explicit user requests to compare/change approaches.

Keep notes short, version-aware and source-linked. Do not store API keys, credentials, customer data, or private project source in the vault.
