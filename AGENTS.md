## Rules for AI Agent

- Always create a plan first for large scope tasks.
- At the end of task, always make a detailed report on what was done

## Task workflow

For implementation tasks:

1. Read the task specification and relevant project instructions. Identify acceptance criteria, constraints, and dependencies before making changes.
2. Plan the implementation and validation before editing. Keep the plan proportional to the task.
3. Implement the task and run appropriate checks.
4. Review the implementation against the specification and the diff. Fix issues found and rerun affected checks.
5. Commit the completed changes. Preserve unrelated work and report any reason a commit could not be made.
6. Give the user a detailed report of what changed, the review and checks performed, the commit, and any remaining limitations.

Do not claim unperformed validation or commit unrelated user changes. If a task is incomplete or blocked, report its actual state rather than presenting it as completed.
